# Changelog

All notable changes to NexNote will be documented in this file.

The format follows Keep a Changelog, and this project uses semantic versioning.

## [1.0.0] - 2026-05-04

### Added

- Initial private GitHub-ready repository setup.
- Single-module Android app structure with Kotlin, Jetpack Compose, Material 3, Room, DataStore, Coroutines, and Flow.
- F-Droid/IzzyOnDroid Fastlane metadata skeleton.
- GitHub Actions build and release workflows.
- GPL-3.0-only licensing, privacy policy, contributing guide, security policy, issue templates, and pull request template.
